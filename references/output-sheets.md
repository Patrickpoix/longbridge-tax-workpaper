# 输出工作表与交付层级

## 完整工作簿

默认完整工作簿至少包含：

- 年度纳税汇总
- 财产转让计税情景
- FIFO已实现盈亏
- 移动平均已实现盈亏
- 盈亏方法差异
- 年末剩余批次
- 持仓数量对账
- 期初逐月持仓对账
- 期初成本批次
- 股息与预扣税
- 融资利息应计
- 融资利息实际支付
- 全部交易
- 全部资金流水
- 全部持仓
- 月度覆盖
- 年末汇率
- 复核就绪性
- 文件追溯
- 版本信息

关键勾稽：

1. 年度汇总中的股息、抵免候选和实际请求应用的抵免应与股息明细一致。
2. 默认抵免应用额为 0；用户请求时应用额不得超过中国税额，并保留证据 WARNING。
3. FIFO、移动平均和三种亏损抵减情景从逐笔处置明细独立汇总；默认主方法不删除审计对照方法。
4. 未实现盈亏不得进入年度财产转让汇总。
5. 缺少年末汇率时，所有受影响的 CNY 字段应为空而不是 0。
6. 期初逐月持仓对账和年末持仓对账应分别核对。

## 三层 ZIP

- `workpapers.zip`：最高敏感级别，完整审计证据。
- `processed_delivery.zip`：无原 PDF，但仍含账户/交易/持仓/来源追溯，仍敏感。
- `sanitized_delivery.zip`：只用于去标识化汇总复核。

sanitized workbook 的工作表集合必须精确为：

```text
年度纳税汇总
财产转让计税情景
年末汇率
复核就绪性
版本信息
```

其中账户值改为“已脱敏”，复核“说明”列改为“详见完整底稿”；不得包含交易明细、持仓、文件追溯或原文资金流水。
